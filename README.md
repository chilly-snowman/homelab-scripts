# homelab-scripts

Scripts for my Ubuntu homelab server (MacBook Early 2015).

## Scripts

| Script | Description |
|---|---|
| `topgear_auto_sort.py` | Watches /srv/media/raw and sorts Top Gear rips by season/episode |
| `post_ingest_watch.sh` | Post-ingest watcher, triggers Jellyfin scan |
| `organize_media.py` | One-time media organizer (reference) |
| `sort_new_shows.py` | One-time show sorter (reference) |
